# 精确记录与模糊记录

精确模式一篇一潜，兼容所有旧日志。模糊模式一篇记录多次经历，必填国家、地区或潜点、时间和潜水次数；其他数据选填。

例：菲律宾 / 妈妈岛 / 2024年3月 / 12潜，潜点 Monad Shoal 与 Gato Island。列表只展示一篇，潜数增加12，到访潜点增加2。年份可折叠组同时显示潜水次数与日志篇数。

- 时间可精确到年、月、某一天或同年日期范围。数据库用时间范围起点排序，展示保持原本精度，不展示虚构的具体日。跨年经历按年份分开，避免猜测年度分布。
- 模糊日志占用连续潜水编号范围，例如001–012；下一次精确潜水编号013。总潜数、年潜数、百潜勋章按潜水次数计算。
- 最大深度与最长单次水下时间参与个人纪录。累计水下时间为单独选填字段，未知则不计入累计时间，不用最长单次时间乘潜数。
- 模糊日志的地点标题取地区或第一个已知潜点。地区不会被当作已知潜点计数。
- 瓶数默认不累计，勾选后按潜数累计；装备仅勾选整段经历每次都使用的装备，所选每件按潜数累计。编辑次数、模式、勾选及删除记录均应用差额；复制上一条会重置所有累计勾选。
- 离线草稿支持相同模式、时间精度和多个潜点，联网同步只创建一篇。离线入口沿用现有规则，瓶数及装备选项需同步后在线编辑。
- 请勿将已经逐次录入的潜水重复包含在模糊记录中；不自动拆成单潜或推测每次测量值。
